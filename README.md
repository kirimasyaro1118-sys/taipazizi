# タイパ時事履修 (taipazizi) 📺⚡

テレ東BIZの2分以下短尺ニュース動画を自動収集し、ブラウザで効率的に時事ニュースを短時間で履修（連続再生・既読管理）できるWebダッシュボード＆YouTube自動同期システムです。

---

## ✨ 主な特徴

- ⏱️ **短時間で時事アップデート**: 2分（120秒）以下の要約ニュース動画のみを自動抽出。
- 📺 **連続再生機能**: 「▶ 続きから再生」を押すだけで未視聴のニュースを連続スムーズ視聴。
- 📱 **マルチデバイス対応**: スマホ・タブレット・PCの全画面サイズに最適化されたモダンデザイン。
- 🔒 **閲覧者ログイン完全不要**: 各端末のブラウザ内（`localStorage`）で視聴履歴・既読状態を完結。
- 🔄 **全自動同期＆フォールバック**: 1日1回の定時自動更新と、通信障害・API上限時のキャッシュ表示機能を搭載。

---

## 🚀 使い方

### 1. Webダッシュボードの起動
`1_GUI起動_Webダッシュボード.bat` をダブルクリックします。  
自動的にローカルサーバーが起動し、ブラウザで Web ページ（`http://localhost:8000`）が開きます。

### 2. 手動での最新ニュース同期
`2_対話実行_手動同期.bat` を実行すると、YouTube API 経由でチャンネルから最新の短尺ニュースを取得・再生リストへ追加します。

### 3. 定期自動更新のセットアップ
`setup_task.ps1` を実行すると、毎日 18:00 に全自動で最新ニュースを同期する Windows タスクスケジューラ（`TxBizNewsAutoSync`）が登録されます。

---

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, Vanilla CSS3 (CSS Variables, Flexbox/Grid), JavaScript (ES6+)
- **バックエンド**: Python 3 (http.server, Google API Client Library)
- **API / データ連携**: YouTube Data API v3, Google OAuth 2.0
- **データ保持**: YouTube Unlisted Playlist, Local Storage, JSON Cache
